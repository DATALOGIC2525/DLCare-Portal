# 修正内容の確認 (Walkthrough)

サイドバーの開閉（トグル）機能を実装しました。アイコンのみの表示に切り替えることで、メインコンテンツの表示領域を広げることができます。

## 変更内容

### 1. サイドバーのコンポーネント化
- サイドバーのロジックを `DashboardSidebar` というクライアントコンポーネントに分離し、インタラクティブな動きを可能にしました。
- ユーザー情報や権限、未読件数などのデータは、サーバーサイド（`layout.tsx`）で取得したものをプロップスとして渡しています。

### 2. 開閉（トグル）機能
- サイドバー上部にトグルボタン（「<」アイコン）を追加しました。
- クリックすることで、横幅を `240px` から `80px` にスムーズに変更します。
- 折りたたみ時はテキストラベルを非表示にし、アイコンのみを表示します。

### 3. 状態の永続化
- `localStorage` を使用して、ユーザーが選択した開閉状態をブラウザに保存します。
- ページをリロードしたり、別のページに遷移したりしても、直前の状態が維持されます。
