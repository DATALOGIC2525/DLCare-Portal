# サイドバーの開閉（トグル）機能の実装

サイドバーを「通常状態」と「アイコンのみの折りたたみ状態」で切り替えられるようにします。これにより、メインコンテンツの表示領域を広く確保できるようになります。

## ユーザーレビューが必要な項目
- **折りたたみ時のツールチップ**: アイコンのみになった際、ホバーしたときにメニュー名を表示するかどうか。（今回はまずシンプルな非表示で実装します）
- **状態の保存**: ブラウザを閉じても開閉状態を維持するために `localStorage` を使用します。
