# マイページ（所有システム情報表示）機能の追加

ユーザーが自身の登録情報、所属企業の保守情報、および所有しているシステム（ソフトウェア）の一覧を確認できる「マイページ」を新設します。

## 背景と目的
現在、ユーザー側のダッシュボードには利用可能なサービスの一覧が表示されていますが、自身の契約内容や所有しているシステム情報を確認する手段がありませんでした。「マイページ」を新設することで、ユーザー自身が契約状況や所有システムをいつでも確認できるようになり、SaaSポータルとしての利便性と信頼性が向上します。

## Proposed Changes

### 1. ナビゲーションの追加
サイドバーメニューに「マイページ」へのリンクを追加します。

#### [MODIFY] `src/app/dashboard/layout.tsx`
- サイドバーの「お知らせ」と「ユーザー管理」の間に、新しく「マイページ」のナビゲーションリンクを追加します。アイコンは `User` を使用します。

### 2. マイページ画面の作成
ユーザーが自身の情報と所有システムを確認できる専用の画面を作成します。

#### [NEW] `src/app/dashboard/mypage/page.tsx`
- サーバーコンポーネントとして実装し、現在のログインユーザーの情報をデータベースから取得します。
- 以下の3つのセクションをカード形式で配置し、「マイページらしさ」を演出します。
  1. **アカウント設定（編集可能）**：氏名、メールアドレスの変更、およびパスワードの変更機能。
  2. **ご契約・保守情報（閲覧のみ）**：企業名、保守ID、利用開始時期、支払方法、備考など。
  3. **所有システム状況（閲覧のみ）**：管理者が登録した `TenantSoftware` の一覧をテーブル形式で表示。

### 3. プロフィール更新用 Server Action
ユーザーが自身の情報を更新するためのアクションを作成します。

#### [NEW] `src/app/dashboard/mypage/actions.ts`
- 氏名、メールアドレスの更新処理。
- パスワード変更処理（現在のパスワード確認、新しいパスワードのハッシュ化保存）。

### 4. 所有システム表示テーブルコンポーネント
マイページ内で使用する、見やすい所有ソフト一覧テーブルを作成します。

#### [NEW] `src/app/dashboard/mypage/user-software-table.tsx`
- 管理画面のテーブルと似ていますが、ユーザー側は閲覧専用とするため、編集・削除ボタンを省いたシンプルなテーブルとします。
- カテゴリ（DL Care等）ごとにグループ化して表示し、見やすさを確保します。

## Verification Plan

### Manual Verification
1. 開発サーバーを起動し、一般ユーザーまたはテナント管理者としてログインする。
2. 左側サイドバーに「マイページ」メニューが表示されていることを確認する。
3. 「マイページ」をクリックし、自身のアカウント情報や企業情報が正しく表示されているか確認する。
4. 管理画面から設定した「所有ソフト情報」が、マイページ上で正しく一覧表示（読み取り専用）されていることを確認する。
