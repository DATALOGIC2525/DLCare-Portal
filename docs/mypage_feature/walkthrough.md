# マイページ機能の実装完了報告

ユーザーが自身の情報を管理し、契約状況を確認できる「マイページ」機能を実装しました。

## 実装内容
### 1. マイページ画面 (`/dashboard/mypage`)
- **アカウント設定**: 氏名とメールアドレスの変更、およびパスワードの変更が可能です。
- **企業・保守情報**: 所属企業の名称、保守ID、利用開始時期、支払方法、備考をカード形式で表示します。
- **所有システム一覧**: 管理者が登録した所有ソフトウェアの情報を、カテゴリ別に整理されたテーブルで閲覧できます。

### 2. 安全なプロフィール更新
- パスワード変更時には「現在のパスワード」の入力を必須とし、セキュリティを確保しています。
- 新しいパスワードはハッシュ化（bcrypt）して保存されます。
- `revalidatePath` を使用し、更新後即座に画面に反映されるようにしています。

### 3. UI/UXの最適化
- サイドバーに「マイページ」メニューを追加し、どこからでもアクセス可能にしました。
- Lucideアイコンを活用し、情報の種類が直感的に伝わるようにデザインしました。
- レスポンシブ対応により、モバイル環境でも情報の確認や編集が可能です。
