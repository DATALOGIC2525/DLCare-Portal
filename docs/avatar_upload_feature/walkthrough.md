# 修正内容の確認 (Walkthrough)

マイページからユーザー自身のアイコン（アバター画像）をアップロード・変更できる機能を実装しました。

## 変更内容

### 1. データベースの更新
- `User` テーブルに画像のパスを保持するための `avatarUrl` フィールドを追加しました。
- `npx prisma db push` により、ローカル環境のSQLiteデータベースに反映済みです。

### 2. アバター画像のアップロード機能
- マイページ (`src/app/dashboard/mypage/page.tsx`) に「プロフィール画像」セクションを追加しました。
- 画像の上にマウスを乗せるとカメラアイコンが表示され、クリックすることで画像ファイル（JPEG, PNG等）を選択できます。
- サーバーアクション `updateAvatar` により、選択された画像は `public/uploads/avatars` ディレクトリに保存され、データベースが更新されます。

### 3. 各画面への反映
- マイページのプロフィール設定画面および、サイドバーのユーザー情報欄において、画像がアップロードされている場合はその画像を表示し、されていない場合は従来のイニシャル＋グラデーションを表示するように対応しました。

## 確認手順
1. ブラウザで [マイページ](http://localhost:3000/dashboard/mypage) を開きます。
2. 追加された「プロフィール画像」の円形アイコンをクリックして、任意の画像ファイルを選択してください。
3. アップロード完了後、マイページ内のアイコンおよび左側サイドバーのアイコンが即座に切り替わることを確認してください。
