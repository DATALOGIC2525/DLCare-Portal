# 修正内容の確認 (Walkthrough)

お知らせ管理において、公開日時を指定して投稿できる「予約投稿機能」を実装しました。

## 変更内容

### 1. データベース層の拡張
- `Announcement` モデルに `publishedAt`（公開予定日時）フィールドを追加しました。
- デフォルトでは作成時の日時がセットされ、即時公開となります。

### 2. 管理画面の機能追加
- **新規作成・編集**: 「公開予定日時」の入力欄を追加しました。未来の日時を指定することが可能です。
- **ステータス表示**: 公開設定が「公開する」かつ日時が未来の場合、一覧に「予約投稿」というラベルが表示されるようにしました。

### 3. 表示制御の実装
- **ユーザー画面**: `publishedAt` が現在時刻以前のお知らせのみを表示するようにフィルタリングを追加しました。
- **未読件数カウント**: サイドバー等に表示される未読件数も、公開済みのお知らせのみをカウント対象にするよう修正しました。

## 確認手順
1. [お知らせ管理画面](http://localhost:3000/dashboard/admin/announcements) を開きます。
2. テスト用のお知らせを作成する際、「公開日時」に数分後の未来の日時を指定します。
3. 作成後、管理画面の一覧で「予約投稿」と表示されていることを確認します。
4. 別ブラウザまたは一般ユーザー権限でログインし、[お知らせ一覧](http://localhost:3000/dashboard/announcements) にそのお知らせが表示されていないこと、および未読バッジが増えていないことを確認します。
5. 指定した時間になった後、ページをリロードして表示・カウントされることを確認します。
