# DLCareポータルサイト構築 提案依頼書 (RFP)

## 1. プロジェクトの背景と目的
### 1.1 背景
株式会社データロジックは、顧客に対して多様なソフトウェア（REAL4、S/F com-pass 3DView等）やサポートサービス（く～chat、オンラインセミナー等）を提供しています。しかし、現状は各サービスへのアクセス経路が分散しており、顧客の利便性低下や、管理者側のライセンス・権限管理の煩雑さが課題となっています。

### 1.2 目的
本プロジェクトは、すべての提供サービスを統合的かつセキュアに提供するための「DLCareポータルサイト」を新規構築することを目的とします。
- **顧客満足度の向上**: 単一のダッシュボードから全サービスへシームレスにアクセス可能な環境の提供。
- **管理業務の効率化**: 顧客企業（テナント）ごとのサービス利用権限、ソフトウェア保有状況、アカウントを一元管理。
- **モダンなSaaS体験**: 洗練されたUI/UX（ダークモード対応、グラスモーフィズム等のモダンデザイン）によるブランド価値の向上。

## 2. プロジェクトのスコープ
本システムのスコープは以下の通りです。
1. **マルチテナント基盤の構築**: 顧客企業（テナント）と所属ユーザー（一般、テナント管理者）の階層管理。
2. **認証・認可機能**: NextAuth.jsを用いたセキュアなログインと、役割（システム管理者、テナント管理者、一般ユーザー）に応じたアクセス制御。
3. **ダッシュボード機能**: 顧客が契約しているサービスのみを動的に表示するランチャー機能。
4. **外部システム連携**: 外部提供サービス（Kasanare AIチャット、Uliza動画配信など）のシームレスな統合・認証情報自動引き継ぎ。
5. **システム管理機能**: システム管理者（株式会社データロジック）向けの全体設定、テナント管理、お知らせ配信機能。

## 3. ターゲットユーザーと要件
### 3.1 ターゲットユーザー
- **システム管理者（データロジック社）**: システム全体、全顧客テナント、サービスカタログを管理。
- **テナント管理者（顧客企業の担当者）**: 自社の一般ユーザーのアカウント管理、利用状況の確認。
- **一般ユーザー（顧客企業の従業員）**: ダッシュボードからの各サービスへのアクセス、お知らせの閲覧。

### 3.2 機能要件（ハイレベル）
- ロールベースのアクセス制御（RBAC）
- テナント別のサービス表示・非表示切り替え（デフォルトON機能含む）
- ダウンロードリンク（バリアント）へのアクセス権限管理
- テナント固有およびユーザー固有の外部サービス認証情報（ID/パスワード）の保持とクリップボードコピー機能
- 事前発行IDを利用した、セキュアなユーザー新規登録フロー

## 4. 非機能要件
- **アーキテクチャ**: Next.js (App Router), React, Tailwind CSS
- **データベース**: SQLite (Prisma ORMを利用) ※将来的にはPostgreSQL等への移行も視野に入れる
- **パフォーマンス**: 開発環境におけるTurbopackの活用、本番環境でのサーバーサイドレンダリング(SSR)・静的生成(SSG)の最適化による高速な画面描画。
- **セキュリティ**: パスワードのハッシュ化(bcrypt)、環境変数による機密情報管理。システム管理アカウントの誤削除防止機構。

## 5. 提案依頼事項
提案ベンダーには以下の事項についての具体的なアプローチ、スケジュール、見積もりを求めます。
1. UI/UXの具体的なデザイン案（SaaSらしいモダンなダークテーマ基調）。
2. Next.js 16 (App Router) を活用した、堅牢なシステムアーキテクチャ設計。
3. 開発、テスト、本番移行までのプロジェクトスケジュール。
4. 納品後の保守・運用体制（GitHub Actions等を利用したCI/CDパイプラインの構築含む）。
