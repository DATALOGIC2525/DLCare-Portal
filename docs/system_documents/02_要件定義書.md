# DLCareポータルサイト 要件定義書

## 1. システム概要
DLCareポータルサイトは、株式会社データロジックが顧客に提供するソフトウェア、サポート機能、ウェビナー等へのアクセスを統合したマルチテナント型のウェブプラットフォームです。顧客企業ごとに専用のダッシュボードを提供し、ライセンス状況や必要なサービスへのシームレスなアクセスを実現します。

## 2. ユーザーロールと権限
1. **SYSTEM_ADMIN (システム管理者)**
   - 株式会社データロジックの管理担当者。
   - 全テナント（顧客企業）の作成・削除・情報編集、サービスの追加・編集、お知らせの配信が可能です。
   - ※特別アカウント「株式会社データロジック (システム管理)」は誤削除防止の保護対象となります。
2. **TENANT_ADMIN (テナント管理者)**
   - 各顧客企業の代表担当者。
   - 自社の「一般ユーザー」のアカウント発行（事前発行IDを利用）、自社ユーザーの利用状況確認が可能です。
3. **GENERAL_USER (一般ユーザー)**
   - 顧客企業の従業員。
   - マイページでのプロフィール編集、ダッシュボードでのサービスアクセス、お知らせの閲覧が可能です。

## 3. 機能要件
### 3.1 認証・アカウント管理機能
- **ログイン/ログアウト**: メールアドレスとパスワードによる認証。開発環境用のクイック入力機能サポート。
- **アカウント登録**: システム管理者が発行した「事前発行ID（Pre-issued ID）」を使用したセキュアな新規登録フロー。
- **マイページ**: パスワード変更、プロフィールの更新機能。

### 3.2 ダッシュボード機能
- **サービスランチャー**: 契約しているサービスへのリンクをアイコン付きのカード形式で一覧表示。
- **外部認証情報のコピー**: 別途ログインが必要な外部サービス（く～chat等）のID・パスワードをワンクリックでコピーするUIの提供。
- **ダウンロード機能**: 顧客企業ごとに許可されたソフトウェアの最新版（バリアント）をダウンロード可能なボタンの表示。

### 3.3 システム管理機能（マスター管理）
- **テナント管理**: 新規テナントの登録（登録時にデフォルトで全サービスアクセス権を付与）、上限ユーザー数の設定、保守情報（保守ID、開始年月、支払方法）の管理。
- **テナント削除機能**: 確認ダイアログ付きの物理削除機能。関連するユーザーや設定情報を連鎖的(Cascade)に削除。
- **サービス表示制限**: テナントごとにダッシュボードに表示するサービスをチェックボックスで個別にON/OFFできる機能。
- **ユーザー管理（一覧）**: 登録済みの全ユーザーを企業ごとに一覧表示。メルマガ配信等に利用可能なCSVダウンロード機能。システム管理者は一覧から除外。

### 3.4 サービス管理機能
- **サービスカタログ管理**: システム全体のサービス追加、アイコン設定（Lucideアイコン）、URL設定、グループ分け。
- **バリアント（製品種別）管理**: 各サービスに紐づくダウンロードリンク等のバリアント設定機能。

### 3.5 お知らせ（通知）機能
- **お知らせ配信**: リッチテキスト（マークダウン等）での全体向けお知らせ作成。
- **既読管理**: 各ユーザーがダッシュボードでお知らせを開いた際の既読状態（UserAnnouncementRead）のトラッキング。未読数のバッジ表示。

## 4. 非機能要件
### 4.1 動作環境
- **クライアント**: Google Chrome, Microsoft Edge, Safariの最新版（PC向け最適化）。
- **サーバー**: Node.js環境。Next.js 16による稼働。

### 4.2 セキュリティ
- セッション管理はNextAuth.jsを使用。
- パスワードはbcryptによる不可逆ハッシュ化を行いデータベースに保存。
- サーバーアクション実行時に、呼び出し元のユーザーロールを毎回検証。

### 4.3 パフォーマンス
- データベースの主要な外部キー（tenantId, userId, serviceId等）に対してインデックス(`@@index`)を付与し検索を高速化。
- 画面共通レイアウトでのデータ取得に `Promise.all` を用い、初期描画の遅延を最小化。
- Lucideアイコンの個別インポートによるJavaScriptバンドルサイズの削減。
