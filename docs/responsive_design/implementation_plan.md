# レスポンシブ設計（モバイル対応）の実装計画

DLCare Portalをスマートフォンやタブレットなどの小さな画面でも快適に利用できるように、UIを最適化します。

## ユーザーレビューが必要な事項
- [ ] モバイル時のサイドバーの挙動（スライドイン形式にするか、下部のタブバー形式にするか）。今回は一般的なスライドイン形式（ハンバーガーメニュー）を想定しています。
- [ ] リボンメニューの表示（モバイルではアイコンを小さくするか、縦に並べるか）。

## 変更内容

### コンポーネントの修正

#### [MODIFY] [dashboard-sidebar.tsx](file:///d:/%E3%82%BD%E3%83%95%E3%83%88%E9%96%8B%E7%99%BA/DLCare-Portal/src/components/dashboard-sidebar.tsx)
- **モバイル用トグルの追加**: 画面端にハンバーガーメニューボタンを追加します。
- **オーバーレイ表示**: モバイル時はサイドバーを絶対配置（`absolute`）にし、背景を暗くするオーバーレイを実装します。
- **レスポンシブクラスの適用**: Tailwindの `md:` プレフィックスを使用して、デスクトップとモバイルでスタイルを切り替えます。

#### [MODIFY] [ribbon-dashboard.tsx](file:///d:/%E3%82%BD%E3%83%95%E3%83%88%E9%96%8B%E7%99%BA/DLCare-Portal/src/components/ribbon-dashboard.tsx)
- **アイコンサイズの調整**: モバイル時はアイコンとボタンのサイズを少し小さくし、画面を広く使えるようにします。
- **ヘッダーの調整**: モバイル時に「ポータルサービス一覧」などの文字が重ならないよう、レイアウトを調整します。
- **パディングの最適化**: 狭い画面でもコンテンツが中央に収まるよう、余白を調整します。

#### [MODIFY] [layout.tsx](file:///d:/%E3%82%BD%E3%83%95%E3%83%88%E9%96%8B%E7%99%BA/DLCare-Portal/src/app/dashboard/layout.tsx)
- サイドバーとメインコンテンツの重なりを制御するため、レイアウト構成を微調整します。

## 検証計画

### 動作確認
- ブラウザのデベロッパーツールを使用して、各画面サイズ（iPhone SE, Pixel 7, iPad等）での表示崩れがないか確認。
- モバイル表示でハンバーガーメニューが正しく動作し、サイドバーを開閉できるか確認。
- リボンメニューの横スクロールがモバイルでもスムーズに行えるか確認。
