# DLCareポータルサイト システム概要資料
作成日: 2026年5月7日

## 1. はじめに（システムの目的）
DLCareポータルサイトは、株式会社データロジックが提供する各種ソフトウェアサービス（NC3, REAL4等）およびサポート機能を一元管理するための**顧客専用マルチテナント・ポータル**です。

### 導入のメリット
- **利便性の向上**: 複数のサービスに一つのダッシュボードからアクセス可能。
- **管理の効率化**: 契約企業ごとのユーザー数やサービス利用権限をシステム管理者が統合管理。
- **コミュニケーションの強化**: お知らせ機能やメルマガ配信リストの活用による、迅速な情報提供。

---

## 2. 主要機能一覧

### A. ユーザー向けダッシュボード
- **サービスランチャー**: 契約しているサービス（NC3, REAL4, 見積積算等）のアイコンが並び、ワンクリックでアクセス可能。
- **お知らせ機能**: アップデート情報や休業案内などをダッシュボード上で確認。
- **マイページ**: 自身のプロフィール情報の確認・管理。

### B. テナント管理者向け機能
- **自社ユーザー管理**: 契約上限数内での担当者アカウント作成、権限設定（管理者/一般）、ステータス変更。

### C. システム管理者（マスター）向け機能
- **企業（テナント）マスター管理**: 企業の新規登録、保守IDの発行、サービス利用制限の設定。
- **サービス・バリアント管理**: 表示するサービス名、URL、アイコンの動的な管理。
- **登録ユーザー一覧・エクスポート**: 全テナントの担当者情報を横断的に確認。メルマガ配信用のCSVダウンロードが可能。

---

## 3. 最近の主なアップデート（2026年5月時点）

### ブランディングの刷新
- **ロゴのリニューアル**: 「D」と「C」をモチーフとした新しい公式ロゴを採用し、ログイン画面およびサイドバーをプレミアムなデザインへ更新。

### ユーザー登録プロセスの最適化
- **簡略化された登録フロー**: 登録時の入力項目を最小限（氏名、メール、パスワード、登録ID）に絞り込み、ユーザーの導入負荷を軽減。

### 管理機能の強化（メルマガ対応）
- **データ連携の強化**: マスター管理上の「企業情報（保守ID等）」と「登録担当者」を紐づけて一覧表示・出力できる機能を実装。
- **配信リスト出力**: メルマガ配信に最適な形式でのCSVダウンロード機能を搭載。

---

## 4. セキュリティと構成
- **マルチテナント分離**: データベースレベルで企業ごとのデータを厳格に分離。
- **事前発行ID方式**: システム管理者が発行した特定のIDを持つユーザーのみが登録できる安全な仕組み。
- **モダンな技術スタック**: Next.js (App Router), Prisma, SQLite (開発環境) を採用した高速でレスポンシブなUI。
