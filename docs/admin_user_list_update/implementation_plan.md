# 登録ユーザーリストへの変更とテーブル表示化

登録ユーザー一覧ページ（`/dashboard/admin/users`）のUIを改善し、カード形式からExcelのようなテーブル形式に変更します。また、タイトルを「登録ユーザーリスト」に更新します。

## ユーザーレビューが必要な項目
- **表示形式**: 現在の「企業ごとのグループ化」を維持したまま各企業内をテーブルにするか、全ユーザーを一つの大きなテーブル（企業名カラム付き）にするか。
    - 今回は「企業ごとのグループ化」を維持しつつ、中身をテーブル形式にする構成で提案します。
- **管理機能**: 前回の提案にあった「削除」「ロール変更」ボタンもテーブル内に追加します。

## 検証計画

### 手動確認
- `/dashboard/admin/users` にアクセスし、タイトルが「登録ユーザーリスト」になっていることを確認。
- 各企業のユーザーがテーブル形式で正しく表示されていることを確認。
- レスポンシブ表示（横幅が狭い場合）の挙動を確認。
