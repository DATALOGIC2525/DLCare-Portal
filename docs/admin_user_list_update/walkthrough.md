## 変更内容

- ページタイトルおよびサイドバーのメニュー項目を「登録ユーザー一覧」から「登録ユーザーリスト」に変更しました。

- 従来のカード形式から、`shadcn/ui` の Table コンポーネントを使用したリスト形式に変更しました。

- **表示項目**: 氏名、部署、権限（バッジ表示）、メールアドレス、電話番号。
