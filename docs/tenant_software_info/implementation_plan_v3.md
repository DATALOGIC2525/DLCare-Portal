# ソフト所有情報＆Excelテンプレート準拠 実装計画 (V3)

ご提供いただいたExcelテンプレート（`テンプレート.xlsx`）の内容を正確にシステムへ反映し、先ほどご提示いただいた「所有システム情報の表」と連動するようシステムを改修します。

## 💡 仕様とマッピングの方針（要確認）

Excelテンプレートの構造と、データベースの連携について以下の通り設計します。

### 1. 企業（Tenant）の基本情報として扱う項目
以下の項目は、企業（1社）につき1つずつ設定される情報として扱います。
- **ユーザー名**（企業名）
- **保守ID**
- **開始月**
- **開始年**
- **支払方法**
- **備考**

### 2. 「所有ソフト」として扱う項目（〇がついているもの）
以下の項目は、エクセル上で「〇」がついている場合に、その企業の「所有システム情報」としてシステム内に**複数登録**（1対多のテーブル形式）されるようにします。
- 【DL Care】REAL4
- 【DL Care】見積・取合保守
- 【DL Care】OA保守
- 【DL Care】NC保守
- 【DL Care】Arris保守
- 【DL Care】出荷計画
- 【DL Care】溶接ロボ
- 【DL Care】へ移行中・DW保守はキャンセル

※エクセルには「総数」や「納入日」がないため、インポート時はとりあえず「所有している（〇がある）」という情報のみで登録し、後から画面上で台数や納入日などの詳細を追記・編集できる形式とします。

## 提案する変更内容

### 1. データベースの再構築 (Database Schema)
#### `Tenant` モデルの拡張
- `maintenanceId` (String?) : 保守ID
- `startMonth` (String?) : 開始月
- `startYear` (String?) : 開始年
- `paymentMethod` (String?) : 支払方法
- `remarks` (String?) : 備考
- `softwareCount`, `purchaseDate` は削除します。

#### 新規 `TenantSoftware` モデルの作成
- `id`, `tenantId`
- `name` (String) : ソフト名（例：「REAL4」「OA保守」など）
- `count` (Int?) : 総数（デフォルト1等）
- `purchaseDate` (String?) : 初回納入日（任意入力）
- `lastUpdateDate` (String?) : 最終更新日（任意入力）
- `version` (String?) : Ver.（任意入力）

### 2. インポート機能の改修（CSV/エクセル対応）
現在実装済みのCSVインポートAPIを、**「提供いただいたテンプレート形式のCSV（エクセルをCSV保存したもの）」**を読み込めるように改修します。
- CSVをアップロードすると、各列の値を読み取りデータベースへ登録します。
- 「〇」がついている列のソフトを自動判定し、`TenantSoftware` テーブルに複数件登録します。
- 処理後、登録用IDが発行された結果をダウンロードさせます。

### 3. マスター管理画面 UIの改修
- 企業の詳細パネルに「保守情報（保守ID、開始年月、支払方法、備考）」の編集フォームを追加。
- 詳細パネルに**「所有ソフト情報テーブル」**を追加し、インポートされたソフトの一覧表示と、詳細情報（総数や納入日）の編集・行の追加が行えるようにします。
