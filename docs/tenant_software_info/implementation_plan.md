# ユーザー（企業）へのソフト所有情報追加 実装計画

顧客企業（旧テナント）の登録時に、「ソフトの本数」と「購入時期」を登録し、管理画面の一覧で表示できるようにシステムを拡張します。

## 課題と背景
現在、ユーザー（企業）を登録する際に、企業名とシステム利用の上限数しか設定できません。
サポートや管理を円滑に行うため、各社が「どのくらいソフトを持っているか」「いつ購入したか」を登録・確認できるようにします。

## 💡 仕様に関する質問（User Review Required）

> [!IMPORTANT]
> **「購入時期」の入力形式について**
> 
> カレンダーから正確な「年月日」を選ぶ形式（カレンダーUI）にするか、あるいは自由記述（例：「2024年4月」「2023年冬頃」など）にするか、どちらがご希望でしょうか？
> 
> *特にご指定がなければ、柔軟に入力できる「**自由記述（テキスト入力）**」を採用する予定です。*

## 提案する変更内容

### 1. データベースの拡張 (Database Schema)
企業を管理する `Tenant` モデルに以下のカラムを追加します。
- `softwareCount` (Int?) : ソフトの所有本数（数値）
- `purchaseDate` (String?) : 購入時期（自由記述のテキスト形式）

#### [MODIFY] `prisma/schema.prisma`
- `Tenant` モデルに `softwareCount` と `purchaseDate` を追加。

### 2. 管理者向け：UI画面と登録処理の改修
マスター管理画面に新しい項目を追加し、1件ずつの登録を可能にします。

#### [MODIFY] `src/app/dashboard/admin/page.tsx` & `actions.ts`
- 新規登録フォームと一覧画面に「ソフトの所有本数」「購入時期」を追加。
- Server Action を更新してデータベースに保存。

### 3. 【新規】管理者向け：CSV一括インポート機能
400件近いユーザー情報を一括で登録できる仕組みを作ります。

#### [NEW] CSVアップロードUIの追加 (`src/app/dashboard/admin/page.tsx`)
- マスター管理画面に「CSVインポート」ボタンを追加。
- ファイルを選択すると、非同期で一括登録処理を開始。

#### [NEW] CSV処理用APIエンドポイント (`src/app/api/admin/import-tenants/route.ts`)
- アップロードされたCSVをパースし、各行の「企業名」「利用上限数」「ソフト本数」「購入時期」を元に `Tenant` を一括作成。
- 同時に各企業用の「登録用ID（PreIssuedId）」を自動生成。
- **処理結果として、生成された「登録用ID」を含んだ新しいCSVファイルをダウンロード**できるようにレスポンスを返します。（管理者が各企業にIDを案内するため）
