# DLCare Portal 機能仕様書

## 1. ユーザー権限モデル

本システムには3つの権限が存在し、それぞれの役割に応じてアクセス可能な機能が制限されます。

| 権限 | 説明 | 主な操作 |
| :--- | :--- | :--- |
| **システム管理者** (SYSTEM_ADMIN) | システム全体の管理権限 | テナント管理、全ユーザー管理、サービスマスタ管理、全体お知らせ配信 |
| **テナント管理者** (TENANT_ADMIN) | 各テナント内の管理権限 | 自テナントのユーザー管理、テナント情報の閲覧 |
| **一般ユーザー** (GENERAL_USER) | エンドユーザー権限 | サービスへのアクセス、プロフィール編集、お知らせ閲覧 |

## 2. テナント管理

マルチテナント方式を採用しており、各テナントは独立したデータ空間を持ちます。

- **テナント属性**: テナント名、ユーザー上限数、保守ID、契約期間、支払方法、備考。
- **ソフトウェア管理**: 各テナントが所有するソフトウェア（DL Care, REAL4等）のライセンス数やバージョンを管理。
- **サービス制御**: テナントごとに利用可能な外部サービスを制限可能。

## 3. ユーザー登録フロー（事前発行ID）

セキュリティを確保するため、管理者が事前に発行した「発行ID」を使用してユーザーが自身のアカウントを登録するフローを採用しています。

1. **管理者がIDを発行**: テナントごとにユニークなIDを発行。
2. **登録**: ユーザーが発行されたIDを入力し、自身のメールアドレスとパスワードを設定してアカウントを作成。
3. **アクティベーション**: 登録完了後、即座にログイン可能（テナントのユーザー上限に達していない場合）。

## 4. 外部サービス連携

ポータルサイトから外部サービスへシームレスにアクセスするための機能です。

- **共有資格情報**: テナント単位で設定された共通のログイン情報。
- **個人資格情報**: ユーザー単位で個別に設定されたログイン情報。
- **クリップボード連携**: ログインIDやパスワードをワンクリックでコピー可能。

## 5. お知らせ配信機能

対象を絞った効果的な情報伝達が可能です。

- **配信ターゲット**:
  - 全体配信
  - ロール限定（例：管理者のみ）
  - テナント限定（例：特定の企業のみ）
- **既読管理**: ユーザーごとにお知らせの既読状態を追跡。

## 6. 技術的な仕様

- **データベース**: Prisma ORMを介してSQLiteを利用。
- **認証**: NextAuth.jsによるCredentials認証（JWTセッション）。
- **スタイリング**: Tailwind CSSおよびRadix UIベースのコンポーネントを使用し、レスポンシブデザインに対応。
