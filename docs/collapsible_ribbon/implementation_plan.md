# リボンメニューの折りたたみ機能の実装計画

ダッシュボード上部のリボンメニュー（サービス一覧エリア）を、サイドバーのように折りたたみ可能にし、メインコンテンツ（詳細パネル）の表示領域を広げられるようにします。

## ユーザーレビューが必要な事項
- [ ] 折りたたみ時の表示スタイル（完全に隠すか、最小限のバーを残すか）。
- [ ] 折りたたみ状態をセッション間で保持するか。

## 変更内容

### コンポーネントの修正

#### [MODIFY] [ribbon-dashboard.tsx](file:///d:/%E3%82%BD%E3%83%95%E3%83%88%E9%96%8B%E7%99%BA/DLCare-Portal/src/components/ribbon-dashboard.tsx)
- `isCollapsed` 状態を追加します（初期値は `false`）。
- リボンヘッダーの右側に「折りたたみ/展開」ボタンを追加します。
- `isCollapsed` が `true` の場合、アイコン一覧とグループラベルを非表示にします。
- トランジション（アニメーション）を追加して、スムーズな開閉を実現します。
- 折りたたみ状態を `sessionStorage` に保存し、ページ遷移後も維持されるようにします。

## 検証計画

### 動作確認
- 折りたたみボタンをクリックして、リボンメニューがスムーズに閉じたり開いたりすることを確認。
- 折りたたみ時に下の詳細パネル（iframe等）の表示領域が広がることを確認。
- ページをリロードしても、直前の折りたたみ状態が維持されていることを確認。
