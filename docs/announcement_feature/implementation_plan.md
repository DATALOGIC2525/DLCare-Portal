# お知らせ（通知）機能の実装計画

データロジック管理者（システム管理者）が告知を行った際、すべてのテナントユーザー（および管理者）に通知が行く仕組みを構築します。

## 課題と背景
現在、管理者からユーザーへシステムメンテナンスや新機能追加などの情報を一斉送信・掲示する手段がありません。
ユーザーがログインした際に気づきやすいよう、ポータル画面内にお知らせ機能を追加します。

## 💡 仕様に関する質問（User Review Required）

> [!IMPORTANT]
> **通知の表示方法について、ご希望のイメージはどちらでしょうか？**
> 
> **A案：サイドバーメニュー型（おすすめ）**
> 左側のサイドバーに「🔔 お知らせ」メニューを追加し、未読件数（例：赤丸で `3`）を表示する。クリックするとお知らせ一覧ページが開く。
> 
> **B案：トップバー・ポップアップ型**
> ダッシュボード画面の右上にベルマーク🔔を配置し、クリックすると通知リストがポップアップ（ドロップダウン）で表示される。
> 
> *現在のレイアウト構造上、A案の方がスマホ対応も含めて自然に馴染みやすいと考えておりますが、いかがでしょうか？*

## 提案する変更内容

### 1. データベースの拡張 (Database Schema)
以下の2つのモデルを追加します。
- `Announcement`（お知らせ本体）: タイトル、本文（Markdown/HTML）、作成日時を保持。
- `UserAnnouncementRead`（既読管理）: どのユーザーがどのお知らせを読んだか（既読状態）を管理し、未読バッジの計算に使用。

#### [MODIFY] `prisma/schema.prisma`
- `Announcement` モデルの追加
- `UserAnnouncementRead` モデルの追加
- `User` モデルへリレーションの追加

### 2. 管理者向け：お知らせ管理機能
管理者がお知らせを作成・編集・削除できる画面を作ります。

#### [NEW] `src/app/dashboard/admin/announcements/page.tsx`
- お知らせの一覧表示、新規作成、編集フォーム。
- 詳細説明には、先日追加した「画像アップロード機能付きリッチテキストエディタ」を利用します。

#### [NEW] `src/app/dashboard/admin/announcements/actions.ts`
- お知らせの保存、更新、削除を行うServer Actions。

### 3. ユーザー向け：お知らせ表示機能
ユーザーがお知らせを閲覧し、未読件数を確認できる機能を作ります。

#### [MODIFY] `src/app/dashboard/layout.tsx`
- サイドバー（またはヘッダー）に「お知らせ」メニューと**未読バッジ**を追加。
- サーバー側で対象ユーザーの未読お知らせ数をカウントしてバッジに表示。

#### [NEW] `src/app/dashboard/announcements/page.tsx`
- お知らせの一覧を表示するページ。
- クリックして詳細を開いたタイミングで、既読フラグ（`UserAnnouncementRead`）をデータベースに保存。

## 検証計画 (Verification Plan)

### 自動テスト / 動作確認
1. **マイグレーションの実行**: `npx prisma generate` および `npx prisma db push` が正常に完了すること。
2. **管理者のCRUD操作**:
   - システム管理者でログインし、ダッシュボードから新規お知らせを作成・編集・削除できるか確認。
   - リッチテキストエディタで画像や装飾が正常に保存されるか確認。
3. **ユーザーの未読/既読管理**:
   - 一般ユーザーでログインし、未読バッジが表示されていることを確認。
   - お知らせ詳細を開いた後、未読バッジのカウントが減ること（既読化）を確認。
