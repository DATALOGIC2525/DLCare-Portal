# お知らせ（通知）機能 実装結果の確認 (Walkthrough)

ご希望いただいた「A案（サイドバーメニュー型）」に基づくお知らせ機能の実装が完了しました。

## 実装された機能

### 1. 🔔 サイドバーの未読バッジ
- ダッシュボードの左側メニューに**「お知らせ」**が追加されました。
- 管理者が新しいお知らせを公開すると、未読のお知らせがあるユーザーのメニューに赤い通知バッジ（件数）がリアルタイムに表示されます。

### 2. 📢 お知らせの閲覧と既読化
- サイドバーから「お知らせ」をクリックすると、お知らせ一覧ページが開きます。
- このページを開いたタイミングで自動的に**既読状態**となり、サイドバーの赤いバッジが消えます（未読が0件になります）。
- 未読のまま残っていたお知らせには `New` バッジとハイライトが付き、どれが新しいものか一目で分かります。

### 3. ⚙️ 管理者専用：お知らせ管理機能
- システム管理者のメニュー内「システム管理」の下に**「お知らせ管理」**を追加しました。
- ここから、新規お知らせの作成、編集、下書き保存（非公開）、削除が可能です。
- 本文には、サービス詳細設定と同じ**画像アップロード付きリッチテキストエディタ**が利用できます。

---

## 動作確認の手順

1. **管理者でお知らせを作成**
   - システム管理者アカウントでログインし、左メニューの「システム管理」＞「お知らせ管理」へ進みます。
   - 新規お知らせを「公開する」ステータスで作成して保存します。
2. **通知の確認**
   - 作成後、左メニューの「お知らせ」部分に赤い未読バッジ（`1` など）が点滅していることを確認します。
3. **既読化のテスト**
   - メニューの「お知らせ」をクリックしてお知らせ画面を開きます。
   - 開いた瞬間に既読処理が行われ、サイドバーの赤いバッジが消えることを確認してください。
